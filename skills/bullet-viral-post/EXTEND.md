# 用户自定义配置

此文件用于覆盖 SKILL.md 中的默认设置，修改此文件不会影响核心工作流

---

## 作者偏好（可按需修改）

```yaml
开头策略: 话题直入型  # 可选：观察型、疑问型、场景型、否定型
分点格式: 数字编号(1. 2. 3.)
分点数量: 3-6个
结尾结构: 三句话递进  # 第1句点破本质，第2-3句升华
全篇标点: 句尾不加句号
```

## 自定义禁用词/句式

在此添加你个人想要避免的表达（会叠加到 SKILL.md 的去AI味清单上）：

```
# 自定义禁用词（每行一个）

# 自定义禁用句式（每行一个）
```

## 草稿自动保存

```yaml
enabled: false  # 设为 true 启用自动保存
path: "~/drafts/tweets/YYYY-MM/"  # 保存路径，YYYY-MM 会替换为当前年月
naming: 推文第一句话  # 文件命名规则
```

保存内容包含 YAML 元数据（日期、状态、洞察）和数据指标占位符

## 数据反馈学习

当你发布推文并获得数据后，可以告诉 AI 实际表现，AI 会：
1. 追加测试记录
2. 更新参考案例（高表现 >10K 印象 / 失败 <2K 印象）
3. 每积累 3 条案例，自动优化核心规则

使用方式：直接告诉 AI "这条推文发了之后数据是 XXX"
